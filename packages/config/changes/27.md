The presets catch the same mistakes without the import and SonarJS plugins, the plugins are taken by caret ranges, and the TypeScript peer admits the 6 major alone.

- **ESLint.** `no-duplicate-imports`, with a type import allowed apart from the value import of the same module, replaces `import-x/no-duplicates`, and `import-x/first` and `import-x/newline-after-import` are dropped, since Prettier and import sorting already keep imports together at the top. Of the SonarJS rules, `no-identical-conditions` moves to `no-dupe-else-if`, `no-identical-expressions` to `no-self-compare`, `no-redundant-jump` to `no-useless-return`, `no-gratuitous-expressions` to `@typescript-eslint/no-unnecessary-condition`, which `typed` already sets, `no-use-of-empty-return-value` to `@typescript-eslint/no-confusing-void-expression` in `typed`, with an arrow that hands back a call in shorthand or with `void` left alone, and `cognitive-complexity` to `complexity`, which `base` already sets. `no-all-duplicated-branches`, `no-element-overwrite`, `no-ignored-return`, `no-empty-collection`, `no-unused-collection` and `no-collection-size-mischeck` have no counterpart and are dropped, and `no-extra-arguments` is left to TypeScript, which refuses an extra argument itself. The type-aware counterparts reach TypeScript files alone, so a JavaScript file no longer fails on the value of a call that returns nothing, a condition that is always true or an extra argument. `no-duplicate-imports` has no fix, so `eslint --fix` no longer merges two imports of one module, and it compares the module as written, so `./x` and `./x.js` read as two modules. The package no longer installs `eslint-plugin-import-x` or `eslint-plugin-sonarjs`, so a repository that sets a rule of either installs the plugin and registers it in its own config, as it does React's hooks plugin. Every plugin the package installs is taken by a caret range, and the `typescript` peer is `^6.0.0`.
- **Docs.** The README names the new bug catchers, says every plugin the package installs is MIT licensed and taken by a caret range, and no longer names the LGPL license SonarJS's plugin carried.
- **Tests.** A sample compared with itself, an `else if` that repeats its condition, a return that does nothing, two imports of one module and the value of a call that returns nothing each fail their preset, a type import kept apart passes, and the workflow test holds the plugins to caret ranges with neither dropped plugin in the lockfile.
