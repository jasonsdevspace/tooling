The commit message command reads a comment line as git stores it, in a minor version, since it
refuses a message it passed before.

- **Command.** `check-commit-message` leaves out git's comment lines only from a message the author
  edited, which holds git's own line asking for a message or the scissors line, since git strips
  them only there. A message given with `-m` keeps a line that starts with `#`, and the command now
  reads it, so a tool named on such a line is refused.
- **Docs.** The README says which messages have their comment lines left out.
- **Tests.** A message given with `-m` whose second line starts with `#` and names a tool is
  refused, and one git wrote its own text into still has its comment lines left out.
